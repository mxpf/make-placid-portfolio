# Amazon

A clearer system for a complex global report

For Amazon’s 2023 Sustainability Report, I designed a more editorial system for a dense global reporting program. The 98-page report organizes the story around Environment, Value Chain, and People, using persistent navigation, modular topic openers, and a consistent visual language to connect high-level commitments with detailed performance.

Compared with the previous report, the redesign sharpened the hierarchy, elevated Value Chain into a major section, and standardized the treatment of metrics, charts, photography, tables, and callouts—giving the document stronger rhythm and visual coherence without sacrificing rigor.
